# Squad Decisions

## Active Decisions

- **Squad model:** Use Squad's markdown-first team state committed in-repo so the team persists across sessions and clones.
- **Operating style:** Keep the team human-led; use issue triage and specialist routing, but do not auto-enable `@copilot` issue execution by default.
- **Specialist coverage:** Maintain dedicated specialists for frontend/UX, Azure platform and deployments, WordPress migration/SEO, security, review, and documentation.
- **Platform baseline:** The blog stack is Hugo + LoveIt, hosted on Azure Static Web Apps, deployed by GitHub Actions from GitHub.

## Governance

- All meaningful changes require team consensus
- Document architectural decisions here
- Keep history focused on work, decisions focused on direction
